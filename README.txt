ROWENGER — HTML-прототип редизайна главной

Открыть Rowenger.html двойным щелчком в браузере. Этот файл содержит CSS, JavaScript, все изображения и три видео, сервер и интернет для просмотра не требуются.

Для редактирования: index.html, style.css, app.js, products.js, experience.css, experience.js и папки assets, videos. experience.mjs добавляет видеосекции при сборке.
content.json — сохранённые тексты, цены, изображения и ссылки оригинальной главной от 27.10.2026.
source.json — исходный DOM, сохранён для сверки; в распространяемый архив не включён.
Сборка: node build.mjs, затем node package.mjs.
Локальный просмотр: node serve.mjs → http://127.0.0.1:4173/

Сохранены 7 основных секций, все 8 слайдов, 5 промоизображений, 3 баннера категорий, 5 новинок, 13 популярных товаров, 2 нижних баннера, 4 преимущества, подписка, ссылки и изображения подвала. Всего 49 уникальных изображений. Тексты внутри баннеров сохранены в самих оригинальных изображениях.

Работают переключение слайдов, ленты товаров, поиск по товарам главной, локальное избранное, мобильное меню и кнопка возврата наверх.
Добавлены три видеосекции из референса BORK, посекционная прокрутка с нативным scroll snap и эффектом наслоения (sticky). На компьютере доступна боковая навигация по секциям. Прокрутка мышью, клавиатурой и касаниями остаётся нативной. Высокие секции можно прочитать полностью.
Видео включаются без звука в видимой секции и останавливаются после ухода с экрана. Есть кнопка паузы. При системной настройке уменьшения движения эффекты и автоматическое воспроизведение отключаются.
Источники видео и страница референса указаны в video-sources.json; на видеосекциях есть подпись BORK · Referans videosu. Ролики используются в этом локальном дизайн-прототипе как референс.
Товары, категории, корзина и информационные ссылки ведут на исходный магазин. Некорректные или пустые информационные ссылки оригинала не исправлялись без данных заказчика. Ссылки на админку из изображений подвала намеренно не перенесены.
Избранное сохраняется только в этом браузере, не синхронизируется с магазином. Форма подписки не отправляет данные и явно сообщает об этом после ввода. Вход в аккаунт направляет к действующему сайту. Покупка и оформление заказа в прототипе не реализованы.

Это дизайн-прототип, а не готовая тема Ticimax. Для внедрения требуется перенести стили и структуру в доступные шаблоны/блоки платформы и подключить её реальные обработчики.
